## 📖 Overview

ArchiveX is an open-source platform designed to preserve and organize university past examination questions in one centralized location.

Students can quickly browse, search, preview, and download past questions without relying on seniors or scattered WhatsApp groups.

The project is built with scalability in mind. Version 1 focuses on past questions, while future versions will evolve into a complete academic resource platform.

## ✨ Features (v1)

### Student

- Browse by Faculty
- Browse by Department
- Browse by Level
- Browse by Semester
- Browse by Course
- Search courses
- Preview PDFs
- Download PDFs
- Mobile responsive
- Dark & Light mode

### Administrator

- Secure authentication
- Dashboard
- Manage faculties
- Manage departments
- Manage levels
- Manage semesters
- Manage courses
- Upload PDFs
